# AnoPick

Extrayez la palette de couleurs de n'importe quelle image, vérifiez les contrastes et exportez le résultat.
Gratuit, dans le navigateur : les images restent sur l'appareil.

Conçu par **ANONYX**, Ouagadougou, Burkina Faso. Contact : anonyxdev@gmail.com

## Contenu
| Fichier | Rôle |
|---|---|
| `index.html` | Landing page de présentation (Motion, Lenis) |
| `app.html` | L'application AnoPick |
| `favicon.svg`, `apple-touch-icon.png`, `icon-512.png` | Logo et icônes |
| `sources/` | Sources TypeScript/CSS des effets de l'app et script de build |

## Mettre en ligne avec GitHub Pages
1. Sur GitHub : **Settings → Pages**.
2. **Source : Deploy from a branch**, branche `main`, dossier `/ (root)`.
3. Le site est publié sur `https://<votre-compte>.github.io/<nom-du-depot>/`.

La landing est la page d'accueil (`index.html`) et son bouton mène à `app.html`.
